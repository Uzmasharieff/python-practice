# 🔐 Password Strength Checker

A Python-based password strength checker that evaluates password complexity and provides suggestions to improve password security.

## ✨ Features

- Checks password length
- Detects uppercase and lowercase letters
- Checks for numbers and special characters
- Classifies passwords as Weak, Moderate, or Strong
- Provides suggestions to improve password complexity

## 🛠️ Technologies Used

- Python 3
- String module
- Getpass module

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open a terminal in the project folder.
4. Run:

```bash
python password_checker.py
```

## 🎯 Purpose

Built to practice Python programming and understand basic password security concepts.

## ⚠️ Disclaimer

This tool provides a basic complexity check. It does not guarantee that a password is secure against every attack.
